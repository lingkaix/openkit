# `@openkit/codex-app-server-schema`

This package stores the vendored JSON Schema snapshot for the `codex app-server` JSON-RPC surface consumed by NanoCore's Codex host adapter.

It is intentionally separate from `@openkit/protocol`.

`@openkit/protocol` is OpenKit's own `UI <-> Core` contract, while this package records an external worker runtime boundary.

## Contents

- `generated-schema/` contains JSON Schema files generated by `codex app-server generate-json-schema`.
- `metadata.json` records the generator command, generator version, refresh date, source boundary, and validation expectations.
- `scripts/validate.mjs` validates that the snapshot metadata and required schema files are present and parseable.

## Refresh Procedure

1. Confirm the intended Codex CLI version with `codex --version`.
2. Generate the schema into this package with `pnpm --filter @openkit/codex-app-server-schema generate:schema`.
3. Update `metadata.json` with the generator version, `refreshedAt`, and any maintenance note.
4. Review the generated schema diff before committing.
5. Reconcile NanoCore's Codex adapter if request, response, notification, or error schemas changed in a way that affects normalization.
6. Run `pnpm --filter @openkit/codex-app-server-schema test`, `pnpm --filter @openkit/nanocore test`, and `pnpm run check:repo`.

Do not refresh this snapshot during NanoCore boot or routine test execution.

## Commands

- `pnpm --filter @openkit/codex-app-server-schema test`
- `pnpm --filter @openkit/codex-app-server-schema lint`
