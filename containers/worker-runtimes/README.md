# Worker Runtimes Image

`worker-runtimes` is the deployment image built from `worker-common` in `containers/workers/Dockerfile`. It contains Codex App Server 0.159.2, the Pi 0.99.1 SDK host with its workspace-patched production closure, OpenCode V2 CLI/client 2.0.20, and DeepSeek `@deepseek-ai/dsh` 0.2.0-rc.2. `versions.json` records package identities, the Pi patch digest, and the exact patched MCP module digests; Docker copies it to `/usr/local/lib/openkit/worker-runtimes-versions.json`. The adapter packages and their specifications own the pins. Refresh those together with this manifest and the smoke assertions.

Build with `bash scripts/docker/build-image.sh worker-runtimes` and smoke with `bash scripts/docker/smoke-image.sh worker-runtimes`. Both accept an optional isolated tag. The old leaf targets and directories are removed.

OpenCode and DeepSeek are installed in `/usr/local/lib/openkit/runtime-supply` and resolve through the shim's ancestor module path. Pi is deployed independently to `/usr/local/lib/openkit/pi-runtime-host`; the shim starts `/usr/local/bin/openkit-pi-runtime-host`. Pi's production closure is copied by frozen workspace deployment, preserving native MCP, tool search, private imports and transitive assets. A global unpatched Pi installation is not equivalent. `pi-mcp-adapter` is absent.

Smoke runs as numeric sandbox user 1000:1000. It checks the shared tool and filesystem baseline, all four pins and executable paths, immutable runtime supply, absence of baked policy and `/etc/opencode`, the patched Pi module identities and factory/private imports, and the real static adapters through resident Harness open, inspect, and close. It writes the complete, schema-validated `smoke-package.json` fixture at the fixed AgentSession input path before opening each resident, declares a private empty work slot for that smoke session, and writes session output. Harness initialization therefore finishes before native admission; smoke cleanup removes only its own disposable work slot. The shared baseline also creates and imports a marker module in a disposable writable Python environment without network access. These no-prompt packaging dry runs replace the removed CLI dry-run mode and use synthetic loopback credentials. They prove no live inference, search/call behavior, native configuration discovery, OpenShell enforcement, or NanoHost qualification; those remain separate adapter and A2 live tests.

Image contents and `org.openkit.worker.runtimes=codex,pi,opencode,deepseek` confer no authority. The selected AgentManifest resolves into one immutable AEP, whose `control.adapter.targetRuntime` selects exactly one adapter. The image inherits retained `/sandbox` and `/workspace` volumes, ephemeral `/openkit` control storage, and the fixed zero-argument launcher.
