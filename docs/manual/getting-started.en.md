# Getting Started With OpenKit

> **Scope placeholder:** This page intentionally records what the complete Getting Started manual must contain. It does not yet claim that every described release path or guided experience is implemented.

## This Manual Should Cover

- The supported release artifacts, system prerequisites, and the shortest path to a verified OpenKit installation.
- The first local-mode launch and the first server-mode sign-in, including bootstrap and readiness checks visible to the user.
- Creation or selection of the first Workspace without requiring the user to understand its internal storage or runtime configuration.
- Connection of the first repository, provider, and agent through the default guided path, with manual configuration linked only as an operator fallback.
- Selection of Chat, Task, or Goal Mode for the first piece of work.
- Delegation of one bounded task, inspection of progress, response to a human-attention request, and review of the resulting artifact and evidence.
- The expected success state, safe recovery from each first-run failure, and links to deeper user and operator manuals.
