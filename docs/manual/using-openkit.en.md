# Using OpenKit

> **Scope placeholder:** This page intentionally records what the complete end-user manual must contain. Executable walkthroughs will be added only for behavior available in a supported release.

## This Manual Should Cover

- The Workspace, Thread, Turn, Item, AgentSession, and Artifact concepts a user can see, without exposing internal runtime models as product concepts.
- When to use Chat Mode, Task Mode, and Goal Mode, and how work moves between conversation, bounded execution, review, and completion.
- How to delegate to an agent team, inspect ownership and handoffs, follow long-running work, pause or stop work, and continue from durable history.
- How the Action Center presents approvals, blocked work, risks, questions, and other requests for human attention.
- How to compare, annotate, revise, accept, export, and reuse artifacts and verification evidence.
- How Knowledge is proposed, reviewed, traced to sources, corrected, withdrawn, and supplied to future work.
- How authorization, external effects, credentials, and Policy boundaries appear to users, including when the system must ask before proceeding.
- How OpenKit connects existing specialist systems while leaving their domain data and decisions authoritative.
- Recovery guidance for interrupted work, failed agents, stale context, rejected results, and work that needs a second attempt.
