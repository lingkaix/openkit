# Agent-Usable Operator Guidance

User and operator instructions are maintained and packaged in the independent [OpenKit Operations Skill](../../skills/openkit-ops/SKILL.md). Its references cover installation, configuration, maintenance, recovery and product use. This directory keeps no duplicate manuals.

Use the [public OpenKit Skill](../../skills/openkit/SKILL.md) to discover and invoke running-product operations. The [documentation model](../documentation-model.md#user-manuals) owns operator-reference authority and localization; the [operations Skill specification](../specs/20260910-agent_operator_skill.md) owns packaging and host boundaries.
