# Agent-Facing Naming Cutover

## Intent Revisions

2026-10-17, engineer-approved coordinator assignment: apply one canonical operation and Tool naming rule across the existing agent-facing surfaces before new Knowledge Manager execution. The outcome is one identity and one derived model spelling, with no callable old-name aliases, new capability, compatibility reader or unrelated refactor. [Operation Definition](../../specs/20261002-operation_definition.md#names) owns the rule; [the decision record](../../decisions/20261017-agent_facing_naming.md) preserves its source and limits. L-AK retains all Knowledge Manager-owned documents and implementation. L-ID owns the two shared Tool/runtime specifications for this change only.

## Entry Gate

The initial exact declaration audit found two public operation IDs above the chosen model-name budget and 134 model spellings changed by removal of hyphen folding. Current definitions, not those snapshot counts, decide the repository check. Actual Tool discovery and exact reverse dispatch decide the surface regressions. They are ordinary deterministic L1/L3 checks with no account, Provider, host or network effect. The standalone Retrieval MCP test runs its real local executable over standard input/output; it does not substitute a product Knowledge query.

The only story edit changes the recorded MCP capability spelling in an optional evidence predicate. Admission is re-decided under [L6 Story Acceptance](../../specs/20260529-l6_story_acceptance.md#admission): the same issue-fix and reviewed-merge outcome remains satisfiable from the persona and sole user ask. No call sequence, call count, order, retry restriction or Actor instruction is added. The predicate still inspects whichever capability calls exist. This is artifact admission, not a claimed L6 run or Judge verdict.

## Working Checkpoint

The rename plan was posted before repository implementation. The operation owner and affected references are aligned. Shared naming checks, Worker/Coordinator names and Server/Kernel names are normally merged. Assistant aliases, the two overlength provider operations and the distinct delegated configuration Tool are changed with their callers. The current-source descriptor scan supplements factory checks so an added private factory is not dependent on a fixed family list. It reads literals and ordinary lexical constants; computed, imported and spread-derived names remain subject to runtime supply validation. Current per-call authority remains required; a spelling match must not remove the administration check. The next observable is a complete integrated owner-module gate and an independent review of the actual final diff. Exact red/green output and operational checkpoints remain external execution evidence until closeout.

## Acceptance And Closeout

The repository regression must enumerate current composed operations and actual supplied Tool declarations, without a hard-coded ID count or Knowledge Manager exception, and reject invalid grammar, projected length above 40 and hyphen-folded collisions. Tests also cross discovery, Provider spelling and exact reverse dispatch. Regenerate existing derived outputs, run the applicable complete module/package suites, obtain independent Sol review, and use express landing only on green main. No live provider, host, reset, account, release or tag action is part of this change. Closeout records the landed commit, exact verification, residual findings and raw complexity counts.
