## Accepted Direction

### R005 — Existing Owners, Truthful Terminal State

- Keep the global command primary key and derive each command id as the collision-resistant domain-separated lowercase SHA-256 over the exact canonical complete-lineage, kind, and sequence preimage owned by the Worker Control Protocol; payload is excluded from identity so a changed replay conflicts. Replace `INSERT OR REPLACE` with a non-replacing insert whose exact existing lineage, kind, sequence, and canonical payload is an idempotent durable replay and whose different bytes are a conflict. Exact replay preserves durable status and timestamps, enters memory at most once only for `queued` or `delivered`, and never hydrates `acknowledged` or `undeliverable`. The gateway advances its next sequence and memory only after the durable insert or eligible exact replay wins. Restart derives the exact-lineage high-watermark from every status while hydrating only `queued` and `delivered` rows.
- Use the first exact scheduler lease live-to-`releasing` Core SQLite transaction as the shared race serialization point. Bounded-turn enqueue verifies the complete-lineage lease is still live and inserts or replays its command inside the same `BEGIN IMMEDIATE`; delivery verifies that live lease while changing `queued -> delivered`; acknowledgement serializes `delivered -> acknowledged`; and live-to-`releasing` changes matching `queued` and `delivered` rows to `undeliverable` before commit. The gateway may expose a command, remove it from process-local state, or accept acknowledgement only after the durable CAS wins, and no prior authorization read may be followed by a later insert.
- Align CapabilityCall with its Core owner in one direct cutover: private `queued` and `running` remain nonterminal; the only terminal values are `succeeded`, `failed`, `denied`, `aborted`, `timed-out`, `interrupted`, and `unknown`; `cancelled` is removed. Current cancellation and timeout producers map to `aborted` and `timed-out`. One shared `finishCapabilityCall` Workspace transaction applies every owned CapabilityCall-to-AuditEvent terminal mapping with one terminal instant or rolls both records back; restart recovery calls that seam with `unknown`, retains the existing stable restart error code, and prohibits replay or any stronger inference.
- Schedule bounded-turn command polls from the request-start anchor without a preceding serial heartbeat delay. Preserve the one existing outage budget and prove the selected Worker or private Harness poll under permitted inference saturation, absence of the unselected poll, the private empty-poll 250 ms minimum, the 1000 ms maximum, and the NanoHost-owned 2000 ms authorization-to-supervisor interrupt bound.
- Split the currently over-shared worker schema literal at its existing seam. Public heartbeat and worker-control outer request and response envelopes use a control-only version-2 literal, and private Harness poll, command, and result envelopes use the direct version-2 literal. Runtime-provenance records, transcript and canonical inner records, Workspace change manifests, and inner capability summaries remain on their independently owned version-1 literal. Add no union, negotiation, accepted-version set, registry, or compatibility adapter.
- Admit the enabled OpenCode adapter through the existing NanoHost/Harness transport only as one Turn-private, non-reusable `bounded-turn` binding. It never retains or restores a native handle, never accepts private Harness `turn.interrupt`, uses only the durable Worker `interrupt` command and command poll, and closes its binding after terminalization. NanoCore selects the sole interrupt owner from immutable adapter mode and the Harness rejects bounded-turn `turn.interrupt`. This adds no `opencode serve`, native resume, or session-continuity claim.
- Correct the Worker Turn Reliability current projection: S39 delivery and the NanoHost/Harness production path are implemented, and the supported R005 surface is Codex session-continuity plus OpenCode bounded-turn. Keep the spec Partial only for separately owned or unsupported generic recovery presentation, Pi, full file-backed context replay, autonomous compaction, replacement execution, broader capability/audit producer coverage, and future distributed profiles.
