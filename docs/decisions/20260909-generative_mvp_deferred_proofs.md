# The Generative Apps MVP Defers Live, Browser, And Restart Proofs

## Decision

The first Generative Kernel, Agent, and Generative UI delivery is the simplest foundational MVP that lets users try it and give feedback. Its live selected-Worker journey, browser end-to-end form, edit, and refresh proofs, and crash and restart proofs are deferred under an engineer exception. Typecheck, official A2UI admission, Policy, portability, the CLI bundle, and contract conformance are not waived. The Generative Kernel Data Operations specification records the deferral in its implementation projection.

## Reason

The engineer asked for the simplest foundational MVP that makes Generative Kernel, Agent, and Generative UI work inside OpenKit, so that users can use it, provide feedback, and guide the next improvements. Why these particular proofs were deferred was not recorded separately.

Source: change record 202609090046400001-generative_apps_mvp.

## Rejected Alternatives

None recorded.

## Revisit When

When the generative apps change moves to verification, or when a defect escapes that a deferred proof would have caught.
