## Transition Decision And Exit Evidence

The engineer's accepted [Hosting Goes Through The Gateway MCP](../decisions/20261002-hosting_through_gateway_mcp.md) ends the host publication contract and the entire host repository resource. Platform-managed GitHub writes use an explicitly selected vendor MCP server through the Gateway. Native push requires explicit user-space credentials and admitted receive-pack egress, with no new platform mechanism. Git sources are catalog URL/commit pins; first-release private reads use a user-injected read-only runtime-env token. Canonical non-Git Workspace apply remains separately owned. The legacy specification itself names `docs/specs/retired/` and `Current Guidance: None` once the host implementation is gone.

Retired is the matching terminal state. Worker MCP Tool Supply provides current hosting guidance, but it does not continue the host commit-on-apply, repository resource, publication adapter, push records, or host policy contract. The documentation model distinguishes a new contract in the same product area from substantive supersession. Related surviving concerns have receivers below; their survival does not turn the ended host capability into a replacement contract. Rejected would misdescribe an accepted implemented capability.
