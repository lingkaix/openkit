# Retired Specs

This directory keeps `Status: Retired` specs whose contracts, modules, capabilities, or product directions ended without successor contracts, including deliberate resets.

Retired specs are not current guidance. Each spec must use `Implementation: N/A` and include the lifecycle date, `Current Guidance: None`, decision evidence, a substantive lifecycle reason, and a distinct retention reason required by the parent [specification guide](../README.md).

Use root-level specs and stable core documents as current entry points. Link to files in this directory only when historical evidence is explicitly needed.
