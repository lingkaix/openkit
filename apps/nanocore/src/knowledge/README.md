# Knowledge Format

Knowledge Manager runs have a 300-second default budget. Workspace, Server and User Memory editors read the actual pinned Turn deadline when a Tool runs, including explicit longer or shorter limits; they do not start another fixed default budget. Caller cancellation still fences every editor. The role reports its owned deadline as `knowledge_manager_timeout` in the retained Turn and ordinary failure summary, and keeps caller cancellation distinct. A User Memory failure returns an already sealed role result without appending a late Status Item. No timeout retries a Provider call or notebook effect.

This directory owns the portable OKF v0.2 Markdown parser, OpenKit knowledge-profile validation and the immutable notebook content boundary.

## Boundaries

`source-pointers.ts` validates the shared SourceSummary captured fields and projects existing Source metadata from native `sources/` blobs in Notebook Git. `source-bytes.ts` reads exact bounded ranges or UTF-8 through the shared Storage service and rechecks caller-supplied current admission before delivery. Neither helper supplies Policy authority. A supported SourceSummary whose own `scope` conflicts with its canonical home raises the shared ownership violation; malformed or unsupported Source metadata remains `recovery_required`. `KnowledgeNotebook.readRevision().files` remains Page-only. Its path-qualified `readContent` view supplies exact Page and Source deltas to the existing publisher and Proposal verifiers. Selected Workspace `@sources/<id>.md` transient summaries can edit title, description, tags and body through the same temporary editor, fixed-base publication and exact human Review, including cold reopening and replay. Captured fields, governance and unknown extensions remain unchanged; ordinary edits cannot create, remove or rename Sources. The `@` prefix is invalid for a Page path, so existing Pages below `sources/` retain their identity. Git pointers remain `sources/<id>.md`. Original `/sources` editor bytes remain read-only. `KnowledgeNotebook` preserves native Source blobs across ordinary page candidates; its Source-only candidate method is reserved for the native Source publisher. Raw bytes never enter that tree.

## Native Maintenance Admission

`knowledge-agent-maintenance.ts` exports the closed `ControlMaintenanceAdmissionInputSchema` and `applyControlMaintenanceAdmission(CoreDb | WorkspaceDb, input)` for the existing database worker. The apply function selects the current maintenance Thread, checks its audience and active work, updates its preview, creates the Turn, and inserts the original same-scope command receipt in the caller's savepoint. It opens no database and performs no file effects or commits. Queries receive fresh work identities. A busy maintenance request creates a terminal skipped service Turn without changing the active run or its exclusion. Retained descriptive fields remain intact; unsupported required semantics refuse admission.

Workspace products and receipts share Workspace SQLite. Server products and receipts share Core SQLite. User Memory has private work records in its personal Workspace, while its notebook and command receipt stay User-owned. Those commits are separate effect domains; a User receipt failure does not undo acknowledged Workspace work and does not trigger automatic repair. Immutable Source and Notebook publication keep their existing owners.

The existing control worker exposes `maintenance(database, input)` and validates the closed acknowledged result before FULL COMMIT acknowledgement. SQL failures remain redacted; only declared Notebook and idempotency refusals preserve their typed public meaning. Workspace commands pass their original receipt into admission and do not add a late Main receipt. The preparation helpers and daily scanner are asynchronous. Callers must await admission before using a prepared run, and must await failure publication before releasing their mutation admission or closing owned handles. Provider execution remains outside SQL. Physical database keys include the actual SQLite path and explicit data root; an existing worker binding is never upgraded with a different content mount.
