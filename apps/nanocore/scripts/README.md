# NanoCore Operator Scripts

This directory contains NanoCore build-time and stopped-server helpers. `build-control-store-worker.mjs` runs after TypeScript in the package build and emits `dist/storage/control-store-worker.bundle.mjs` plus its source map with the existing workspace esbuild. Internal static and lazy imports share one bundled instance; native addons and the lazy PDF engine stay external. Each original module keeps a relocatable `dist` resource base. The CI-discovered `src/storage/control-store-worker-bundle.test.ts` relocates this same artifact and checks real native FULL acknowledgements and the ordered close fence. The compiled production selector remains a separate, pending native-client change; ordinary source dev/test entry selection is unchanged. `generate-openapi.ts` and `validate-openapi.ts` own the generated App API projection checks, `migrate-workspace-storage.ts` owns explicit storage migration, `restore-data-root.ts` owns stopped-server restore, and `clean-cancelled-admission-task-checkpoints.ts` owns explicit deletion of proved missing-Turn Task checkpoints. Run them only through the package commands documented in the parent [README](../README.md).
